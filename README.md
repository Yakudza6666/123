# Uzbek LPR (легковесный прототип)

Простое ПО для распознавания узбекских автономеров в стиле "как у Hikvision":
- веб-интерфейс для добавления камер (URL потока);
- тестирование распознавания на видеофайле;
- запись найденных номеров в отдельный файл `data/detections.log`.

## Почему подходит для слабого ПК
- обработка каждого N-го кадра (`frame_step`), что снижает нагрузку;
- классический OpenCV + Tesseract без тяжелых нейросетей.

## Что улучшено по стабильности
- безопасная обработка ошибок OCR и отдельных кадров (приложение не падает на единичных сбоях);
- валидация входных параметров распознавания;
- проверка существования видеофайла до старта обработки;
- устойчивое чтение/запись настроек камер (включая восстановление после битого JSON).

## Что улучшено по качеству распознавания
- несколько вариантов предобработки ROI номера перед OCR (resize + adaptive threshold + Otsu);
- OCR запускается в двух режимах (`psm 7` и `psm 8`);
- постобработка OCR с исправлением частых ошибок (`O↔0`, `B↔8`, `I↔1`) по маске узбекского номера;
- поддержка похожих кириллических символов (`АВСЕНКМОРТХУ` -> латиница).

## Быстрый запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте: `http://localhost:8080`

## Проверка запуска
```bash
python -c "import flask; import app; print('app import OK')"
```

## Использование
1. В разделе **Подключение камер** сохраните RTSP/HTTP адреса камер.
2. В разделе **Тест по видеофайлу** укажите путь к ролику (например `/videos/test.mp4`) и нажмите "Запустить тест".
3. Найденные номера будут:
   - показаны в интерфейсе;
   - записаны в `data/detections.log`.

## Формат узбекского номера
Текущий шаблон: `01A123BC` (`\d{2}[A-Z]\d{3}[A-Z]{2}`).
При необходимости можно расширить regex в `lpr.py`.
